# Drawings

The drawings in the docs are generated by three scripts. They use only the Python standard library, and read the KiCad files directly through [`kicad.py`](kicad.py), a small reader for KiCad's file format.

| Script | Makes | From |
|--------|-------|------|
| [`make_panel_svg.py`](make_panel_svg.py) | `panel.svg`, used in the manual, and `panel-plain.svg`, the panel without captions, used on packaging labels | The faceplate KiCad file |
| [`make_assembly_svgs.py`](make_assembly_svgs.py) | `assembly-*.svg`, used in the assembly guide | The main PCB KiCad file |
| [`make_patch_svgs.py`](make_patch_svgs.py) | `patch-*.svg`, the patch examples in the manual | The faceplate KiCad file |

Run all three from anywhere in the repo after changing the KiCad files:

```sh
python3 docs/drawings/make_panel_svg.py
python3 docs/drawings/make_patch_svgs.py
python3 docs/drawings/make_assembly_svgs.py
```

## Panel drawing

The panel drawing in the [user manual](../manual.md) ([`../images/panel.svg`](../images/panel.svg)) is generated from the KiCad faceplate file, [`4ch Mixer Faceplate.kicad_pcb`](../../hardware/panel/4ch%20Mixer%20Faceplate.kicad_pcb).

### What it reads

| From the KiCad file | Used for |
|---------------------|----------|
| `Edge.Cuts` lines | Panel outline |
| Footprints named `PotShaft`, `Jack` and `MountingHole` | Pot shafts (Ø7.0), jacks (Ø6.0) and rack screw holes (Ø3.2) |
| `F.SilkS` lines, arcs, circles and text | The title, the scales around the knobs, the output rings and the "+" and "−" labels |
| The logo footprint's `F.SilkS` polygons | The Schenktronics logo |

The channels are matched by height: the pot and the input jack on the same row make a channel, numbered from the top. Each of the two output jacks at the bottom is matched to the nearest printed "+" or "−", so the drawings follow the faceplate if the outputs are swapped.

The captions ("In 1", "Knob 1" and so on) are added by the script, not read from KiCad.

## Assembly drawings

After changing the main PCB in KiCad, run `make_assembly_svgs.py`.

| Drawing | How it's made |
|---------|---------------|
| `assembly-1-smd.svg` | Back board view, drawn from the pads, back silkscreen and references in the PCB file. U1's pin 1 and the diodes' cathode pads (pad 1) are marked red. |
| `assembly-2-header.svg` | Back board view with the power header outlined. Pin 1 is marked red. |
| `assembly-3-parts.svg` | Front board view, drawn from the board outline, pads and front silkscreen. The pots and jacks are outlined. |
| `assembly-4-faceplate.svg` | Side diagram, not to scale. The heights are approximate. |
| `assembly-5-solder.svg` | Back board view, with the pot and jack pads to solder first (filled red) and the rest outlined. |

The back views are mirrored left to right, so the SMD side reads as you see it from the back of the board. The back silkscreen text ("−12V", "+12V", "Red Stripe") is placed as a viewer on the back reads it.

## Patch examples

The patch drawings reuse the panel drawing and add module boxes and cables. Each example is a short function in the script, for example:

```python
def inverted(data):
    p = Patch(data)
    p.source("In 4", "LFO", "out")
    p.dest("Out −", "Filter", "cutoff CV in", side="right")
    p.turn("Knob 4", 70)
    return p.render("Patch example: an inverted output")
```

Jacks and knobs are named `In 1`–`In 4`, `Out +`, `Out −` and `Knob 1`–`Knob 4`, from the top. Sources go on the left, destinations on the left or right, beside their output. `turn()` sets a knob's pointer, in degrees from the center click (negative is anticlockwise). `note()` puts a caption beside a knob or jack. Pass `color=BLUE` to draw a second signal. To add an example, write a new function, add it to the list in `main()`, and run `make_patch_svgs.py`.
